## 6. Переписанные требования

| Исходное требование | Переписанное требование | Причина изменения |
|---------------------|-------------------------|-------------------|
| API должен работать быстро | NFR-01: время отклика API — не более 500 мс при 100 записях | Отсутствовал числовой критерий |
| Интерфейс должен быть удобным | NFR-05 + NFR-06: адаптивность от 320px + тёмная тема | Субъективная категория |
| Данные должны быть защищены | NFR-03 + NFR-04 + NFR-10: BCrypt + JWT HS256 + User Secrets | Не указаны конкретные механизмы |
| AI должен качественно анализировать сны | FR-09...FR-13: пять конкретных стратегий анализа | Не было списка методов |
| Система должна поддерживать много пользователей | NFR-01 + FR-05: производительность ≤ 500 мс + разграничение ролей | Неизмеримая величина |
| Код должен быть качественным | NFR-07: покрытие модульными тестами ≥ 70% | Субъективная оценка |
