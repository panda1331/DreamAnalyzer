# Отчет о статической проверке кода

**Дата:** 2026-10-19  
**Инструменты:** `dotnet format` (C#), `ESLint` (React/JS).

## 1. Проверка бэкенда (C#)
Для анализа стиля кода использовалась встроенная утилита `dotnet format`.
При первичном запуске (`dotnet format --verify-no-changes`) было выявлено несколько нарушений типа `WHITESPACE` (неправильные отступы, лишние пробелы) в файлах тестов (например, `AuthServiceTests.cs`).

**Что сделано:** Нарушения были автоматически исправлены командой `dotnet format`. Повторная проверка завершилась без ошибок. Код соответствует официальным рекомендациям Microsoft по оформлению.

## 2. Проверка фронтенда (React)
Для проверки JavaScript-кода использовался линтер `ESLint`.
При первичном запуске было выявлено **6 ошибок и 2 предупреждения**:
* Нарушение правила `react-hooks/immutability` (вызов функции до её объявления в `AdminUsers.jsx`, `AdminDreams.jsx`).
* Неиспользуемые переменные в `DreamDetails.jsx`.
* Нарушение правила `react-hooks/set-state-in-effect` (вызов `setState` внутри `useEffect` в `DreamsList.jsx`, `Header.jsx`, `AdminUsers.jsx`, `AdminDreams.jsx`).

**Что сделано:** Проведен рефакторинг компонентов. Функции загрузки данных обернуты в `useCallback` и правильно указаны в зависимостях `useEffect`. Неиспользуемые переменные удалены. Фильтрация в `DreamsList` перенесена из эффекта в тело рендера. Повторный запуск `npm run lint` показал **0 problems**.
