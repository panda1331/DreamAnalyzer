# План нагрузочного тестирования (Load Test Plan)

## 1. Цели тестирования
*   **NFR-01:** Проверить, что время отклика API на запросы без AI не превышает 500 мс при нагрузке 50 одновременных пользователей.
*   **NFR-09:** Проверить стабильность системы (отсутствие 500 ошибок) при пиковых нагрузках.

## 2. Профиль нагрузки
*   **Действия пользователей:** Авторизация (POST /login) → Просмотр списка снов (GET /Dreams) → Просмотр статистики (GET /users/statistics). 
*   **Одновременные пользователи:** 1 (базовый), 50 (целевой), 100+ (стресс).
*   **Пауза между действиями:** 1-3 секунды.

## 3. Виды тестов
*   **Нагрузочный тест:** Подача целевой нагрузки (50 пользователей) в течение 5 минут.
*   **Стресс-тест:** Линейный рост пользователей (10, 20, 50, 100, 200...) до момента, пока время отклика не превысит 2000 мс или доля ошибок не превысит 5%.

## 4. Критерии успешности
*   **Допустимая доля ошибок:** ≤ 1%.
*   **Допустимое время ответа:** 90% запросов (90-й перцентиль) должны быть быстрее 500 мс.
